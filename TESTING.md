# Тестирование

## Автоматические тесты

```powershell
dotnet test tests/GigaDict.Tests/GigaDict.Tests.csproj -c Release
```

Проверяются state machine горячей клавиши и Esc, игнорирование инъекций, допустимые переходы заданий, запрет password field, Unicode/пробелы/пунктуация, FIFO и единственная конкурентная отправка, лимиты очереди и RAM, WAV-заголовок, HTTP content type/JSON/413/422/429/503/504 и преобразование 48 кГц stereo в 16 кГц mono PCM16.

Регрессионные тесты дополнительно проверяют 30 000 последовательных постановок без гонки состояний, ошибки и отмену передачи результата без остановки worker, изменение лимитов на работающей очереди, последовательность команд при асинхронной остановке захвата, сохранение снимка записи, освобождение захвата без блокировки callback, отбрасывание запоздалых callback предыдущей записи, обычные сочетания Ctrl+C и парность подавленных событий, необратимую блокировку по событию фокуса, восстановление Clipboard при отказе/отмене вставки и отсутствие скрытого HTTP-лимита в 100 секунд. Захват, фокус и Clipboard в этих тестах заменены управляемыми зависимостями; это не аппаратная проверка Windows.

## Обязательный чек-лист Windows 11

- Запуск без повышения прав, одна копия процесса, иконка и выход из трея.
- Горячая клавиша продолжает работать, пока целевое приложение приостановлено (Process Explorer → Suspend) и пока открыты окна настроек/истории.
- Удержание/отпускание F8, auto-repeat, Ctrl+Shift+Space, F9 и правый Alt; Esc не попадает в активное приложение.
- Запись 5 минут, отключение/смена USB-микрофона, устройство по умолчанию и индикатор Windows Privacy.
- Вставка русского/английского текста, emoji и переносов в Блокнот, VS Code, Chrome, Edge, Telegram Desktop, Windows Terminal и обычные Win32 Edit.
- Перемещение каретки в том же поле допускается; переход в другое поле/окно и возврат навсегда запрещают вставку.
- Password/read-only/elevated/Secure Desktop не получают ввод.
- Несколько коротких диктовок подряд при занятом NAS; ответ во время следующего удержания не вставляется до отпускания.
- Быстрые нажатия/отпускания и новая диктовка во время завершения предыдущего захвата; отсутствие зависшей записи и смешения настроек.
- Изменение лимитов очереди и RAM при занятом NAS без перезапуска; уже принятые записи сохраняются и обрабатываются по FIFO.
- HTTP с GigaSTT 2.21.0: сетевой обрыв, 503, timeout, перезагрузка NAS и повтор без автовставки.
- Clipboard: занятый буфер, несколько форматов и изменение буфера другой программой до восстановления.
- Lock/unlock, RDP reconnect, logoff и интерактивный выход с непустой очередью.
- RDP: GigaDict внутри удалённого сеанса, микрофон «Удалённый звук» (перенаправление записи в клиенте) — горячая клавиша, запись и вставка работают (проверено вручную, 1.0.11).
- Проверка single-file EXE на чистой Windows 11 без установленного .NET Runtime.

Эти проверки требуют реальной Windows-сессии, аудиоустройства и NAS; WSL не подтверждает их успешность.
