# Правила разработки GigaDict

- Цель: Windows 11 x64, C#/.NET 10, WinForms; приложение запускается `asInvoker` и не становится службой.
- Перед изменением протокола сверяться только с тегом GigaSTT `v2.21.0`, а не с `main`.
- Никогда не писать аудио или распознанный текст на диск и в логи. История только в RAM.
- При сомнении в фокусе запрещать автовставку. Не применять `SetForegroundWindow`, обход UIPI или автоматический fallback между методами вставки.
- Hook и WASAPI callback не выполняют сеть, UI Automation, ресемплинг или долгую работу.
- Сохранять FIFO и один запрос к NAS. Ожидание вставки не должно блокировать запись и распознавание.
- Новое сетевое повторение должно исключать автоматическую вставку результата.
- Для каждой исправленной ошибки добавлять тест. Запускать `dotnet test` и `dotnet publish`.
- Не утверждать, что Windows/WASAPI/NAS проверены, если тест выполнялся только в WSL.
